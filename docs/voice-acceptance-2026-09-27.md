# v0.3.0 语音交互验收

2026-09-27，本机 macOS / Node 24 / Whisper 20250625、base 模型、CPU 4 线程。范围是本地工作室，未进行公网部署。

## 问题与修复

原有界面能显示浏览器 SpeechRecognition API，但启动时会出现 `network` 错误；失败发生在语音转文字阶段，尚未进入 Jev 判断。现在浏览器通过 `getUserMedia` 和 AudioWorklet 采集，服务端常驻 Whisper 转写，再把文字交给 Jev。此路径不需要浏览器厂商的识别服务，也不新增付费视频任务。

采集保留开头约 0.32 秒，短暂停顿继续组成同一轮，静默约 0.9 秒后提交；单轮约 18 秒封顶。沉默不产生请求，短促点击声被过滤，空转写重新倾听。回应期间关闭输入音轨；播放完延迟 350ms 恢复，避免收进尾音。当前仍是点击主动打断的半双工交互。

回归发现并修复了两处实际问题：小模型将“停一下”听成“请依下”，通过应用词汇上下文和 beam search 改善；正确转写后带逗号又绕过即时停止判断，现已接受常见句末标点，同时保留整句匹配，讨论“暂停”功能不会被误判为停止。

语音接口仅开放本机同源访问，并校验临时会话令牌、WAV PCM 格式、时长与大小，每分钟最多 30 次。服务端启动 45 秒、推理 20 秒、浏览器整次请求 65 秒均有上限；取消会终止当前推理，下一次请求可重新加载。录音不落盘，运行日志不记录声音或转写。Jev 仍收到用户文字和最近对话。

## 实际语音与 Jev 回归

用系统合成声音 Tingting 生成两种语速的中文 WAV，真实调用本地 Whisper 与已配置 Jev；每轮传入前面的用户和助手消息。最终一轮结果如下：

| 输入 | 实际转写 | 回应片段 | ASR | 选片 |
| --- | --- | --- | ---: | ---: |
| 你好，小岚 | 你好：小岚。 | greeting | 1097ms | 546ms |
| 怎么批量制作数字人视频 | 怎么批量制作数字人视频? | batch | 975ms | 422ms |
| 怎么把你接入我的网站 | 怎么把你接入我的网站? | integration | 881ms | 302ms |
| 停一下 | 停一下， | interrupt | 797ms | 0ms，本地停止 |
| 明天北京会下雨吗 | 明天北京会下雨吗? | out-of-scope | 902ms | 296ms |
| 好的，谢谢你 | 好的,谢谢你。 | thanks | 851ms | 303ms |

6/6 选中预期片段；另一个全静音 WAV 返回空文字，推理耗时 0。以上是小样本，不能据此估计开放场景准确率或稳定 P95。ASR 耗时不包括用户说话、0.9 秒停顿判定及视频解码；完整接口往返为 802–1660ms。

本地证据位于被忽略的 `artifacts/interaction/latest.json` 和 `lifecycle.json`，可用 `npm run check:interaction` 重跑。取消实际 Whisper 推理后确认进程退出，下一次请求重新加载并正确识别网站接入问题。使用原始 HTTP 请求验证异源 Origin、非本机 Host 与跨站请求均返回 403。

## 浏览器和工程验证

- Chrome 中用开发面板输入合成声音，经过实际 AudioWorklet、分句、ASR、Jev 和 `/media/batch.mp4` 播放。自然结束后回应隐藏，倾听视频仍为 `paused=false`，会话继续倾听。
- 第二轮网站接入语音正确播放 `/media/integration.mp4`。中途点击“打断并说话”，回应立即暂停，倾听视频继续，语音按钮恢复“正在倾听”。
- 默认桌面和 390×844 手机视口检查：语音入口突出，没有进度条、静默倒计时或横向溢出。手机文字提问“我想把你接到我的网站里，需要怎么做？”正确选中 integration，播放到 10.066 秒；倾听循环持续。
- 设置显示 Whisper 已就绪、Jev 已连接、24/24 视频就绪。应用自身无控制台错误；浏览器其他扩展的警告不属于本应用。
- 45 项测试覆盖分句、静默、噪音短脉冲、请求限制、无效音频、取消、迟到结果、权限晚到、结束后不重启、服务故障恢复和路由；TypeScript 严格检查、Vite 构建、24 条媒体 SHA-256 检查通过。
- `npm run voice:setup` 在本机成功复用现有 Whisper 环境和模型，不重复下载。

## 验收边界

本轮没有启用真实麦克风，没有录制用户环境声音。合成音频覆盖真实浏览器处理和模型推理，但不能替代现场口音、安静说话、噪声、回声与真实麦克风权限的设备验收。模型 warm-up、CPU 负载和更大模型会影响耗时；内容库仍限于 24 条已准备回应。

Whisper 参考：[官方项目](https://github.com/openai/whisper)。浏览器采集参考：[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet)。
