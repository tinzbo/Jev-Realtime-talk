原始生成记录、抽帧和转写保留在本地被忽略的 production / artifacts 目录。仓库包含最终 MP4、素材清单与校验清单；媒体 ZIP 包含 24 个 MP4、台词清单和校验值，CRC 与 SHA-256 已通过。

首批真实 Jev 的 6 个文本样例曾全部选择预期片段，单次耗时 335–698ms。该小样本不代表稳定 P95，也不包含语音识别和媒体首帧加载时间。
